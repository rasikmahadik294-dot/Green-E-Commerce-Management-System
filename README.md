# Green E-Commerce Management System

A web-based e-commerce management system developed using ASP.NET, C# and SQL.

## Technologies Used
- ASP.NET
- C#
- SQL
- HTML
- CSS
- JavaScript

## Features
- User Registration and Login
- Product Management
- Product Browsing
- Shopping Cart
- Order Management
- Admin Management

## Project Overview
This project is designed to provide a simple platform for managing and purchasing eco-friendly products online.
